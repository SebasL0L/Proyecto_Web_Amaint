# AMaint
### Controla. Previene. Optimiza.

**AMaint** es una plataforma de gestión de mantenimiento industrial (CMMS), diseñada para adaptarse a las necesidades operativas de distintas empresas.

El proyecto busca centralizar la administración de activos, mantenimiento, órdenes de trabajo, inventario y análisis operacional mediante una plataforma digital adaptable.

## Objetivo del proyecto

Desarrollar una solución tecnológica escalable y multiempresa que permita a distintas organizaciones gestionar sus procesos de mantenimiento desde un entorno centralizado, configurable y seguro.

## Características principales

- Gestión de empresas y organizaciones.
- Administración de activos y equipos.
- Registro y seguimiento de fallas.
- Gestión de órdenes de trabajo.
- Control de repuestos e inventario.
- Indicadores de mantenimiento.
- Configuración de módulos por empresa.
- Administración central de organizaciones asociadas.
- Gestión de suscripciones y licencias.

## Arquitectura tecnológica

| Componente | Tecnología |
|---|---|
| Backend | Java + Spring Boot |
| Aplicación web | React |
| Aplicación móvil | React Native + Expo |
| Base de datos | PostgreSQL |
| Diseño de interfaces | Figma |
| Control de versiones | Git + GitHub |

## Estructura del repositorio

- `backend/`: lógica de negocio y API.
- `frontend/web/`: aplicación web y portales.
- `frontend/mobile/`: aplicación móvil.
- `docs/`: documentación y planificación.
- `designs/`: diseños y prototipos.
- `infrastructure/`: despliegue e infraestructura.

## Modelo de funcionamiento

AMaint contempla una arquitectura multiempresa, donde cada organización podrá disponer de módulos, configuraciones, usuarios y permisos adaptados a sus necesidades.

La plataforma también contará con un entorno de administración central para gestionar organizaciones, solicitudes de adaptación, licencias y suscripciones.
