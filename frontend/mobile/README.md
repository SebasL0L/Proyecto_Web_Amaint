# AMaint - Mobile Application

Aplicación móvil de AMaint.

## Tecnologías
- React Native
- Expo

## Funcionalidades previstas
- Inicio de sesión.
- Consulta de activos.
- Visualización de órdenes de trabajo.
- Actualización de tareas.
- Registro de incidentes.
- Sincronización con el backend central.

Aplicación orientada principalmente a Android.
